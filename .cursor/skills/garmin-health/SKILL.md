# Garmin Health & Training Status

Выгрузка ежедневных показателей здоровья, восстановления и статуса тренированности из Garmin Connect. Сеть разрешена. Не писать HTTP руками — запускать скрипт.

## Workflow

1. Неделя `ГГГГ-НН` или дата `ДД.ММ.ГГГГ`. Иначе текущая пн–вс. Будущие дни пропускаются.
2. Запустить из корня **с полным доступом к сети** (`required_permissions: ["all"]`):

```bash
.venv/bin/python scripts/garmin/fetch_health.py --week 2026-42
.venv/bin/python scripts/garmin/fetch_health.py --date 15.10.2026
```

3. После успеха: неделя и таблица 7 дней — сон (длительность, оценка), HRV ночь и статус, пульс покоя, Body Battery при пробуждении, готовность, острая/хроническая нагрузка и ACWR, статус тренированности. Отметить тренды и тревожные сигналы (HRV ниже базы, рост пульса покоя, низкая готовность, ACWR > 1.5).

## Авторизация

Как в скилле `garmin-training-log`: токены в `~/.garminconnect`; при ошибке входа пользователь сам запускает `.venv/bin/python scripts/garmin/garmin_login.py` в терминале. Пароль в чате не спрашивать, токены не печатать.

## Таблицы (`2026-2027/garmin/`)

- `daily health.csv` — строка на день. Сон за дату D — ночь, закончившаяся утром D: отбой/подъём, фазы, оценка и качество, потребность во сне, пульс/дыхание/SpO2/стресс во сне, Body Battery за ночь, дневной сон. HRV: ночь, макс. 5 мин, 7 дней, базовый диапазон, статус. Пульс покоя (день и 7 дней), Body Battery (пробуждение, макс/мин, заряд/расход), стресс по зонам, шаги, этажи, калории, минуты интенсивности, дыхание и SpO2 днём, гидратация, вес/жир/мышцы (если есть весы).
- `training status.csv` — строка на день: утренняя готовность (балл, уровень, вклад факторов), время восстановления, статус тренированности, острая (7 дн) и хроническая (28 дн) нагрузка с оптимальным диапазоном, ACWR, фокус нагрузки за 4 недели (анаэробная / высокая / низкая аэробная — факт и цели), VO2max, фитнес-возраст, акклиматизация к жаре/высоте, Endurance Score, Hill Score (сила/выносливость), прогнозы 5/10/21,1/42,2 км, лактатный порог.

## Переводы

| Garmin | CSV |
|---|---|
| `PEAKING` | Пик формы |
| `PRODUCTIVE` | Эффективность |
| `MAINTAINING` | Поддержание |
| `RECOVERY` | Восстановление |
| `UNPRODUCTIVE` | Непродуктивность |
| `DETRAINING` | Детренированность |
| `OVERREACHING` | Перетренированность |
| `STRAINED` | Перенапряжение |
| `NO_STATUS` | Нет статуса |

Статус HRV: `BALANCED` Сбалансирован, `UNBALANCED` Несбалансирован, `LOW` Низкий, `POOR` Плохой. Уровень готовности: `PRIME` Отличная, `HIGH` Высокая, `MODERATE` Средняя, `LOW` Низкая, `POOR` Плохая. Отзывы (`feedback`) пишутся исходной фразой Garmin в нижнем регистре.

## Правила

- Скрипт заменяет дни выбранной недели, остальные строки не трогает. Руками CSV не переписывать.
- Сырые ответы — в `.garmin_cache/days/<ГГГГ-ММ-ДД>/` и `.garmin_cache/weeks/`; пустую колонку сначала проверить там.
- Метрики, которых нет у модели часов (Hill/Endurance Score, акклиматизация и т.п.), остаются пустыми — это нормально.
- Не трогать архив Polar (`cardio load/`, `training log/`) без просьбы.
- Не выдумывать значения, если API не ответил.
